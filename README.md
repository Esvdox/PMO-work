## Что внутри

- `index.html` — публичный дашборд (3 ветки: Портфель, Инициативы, Бэклог)
- `prompt-daily-update.md` — инструкция для Claude Cowork по ежедневному обновлению из xlsx

## Стандарты

- PMBOK 8 (PMI 2025)
- ГОСТ Р 54869-2011
- ISO 21502:2020
- Регламент PMO v4.3

## Обновление данных

Делается локально через Claude Cowork:

1. Открой Cowork, укажи папку: `C:\Users\sivanov\Desktop\Repo-for-claude-ppm-status`
2. Дай задачу: «Выполни `prompt-daily-update.md`»
3. Cowork обновит `index.html` из `PMO_Portfolio_Master_v6.xlsx` и запушит в GitHub
4. Через 1-2 минуты обновится публичная ссылка

## Конфиденциальность

`PMO_Portfolio_Master_v6.xlsx` и `backups/` — в `.gitignore`, на публичный GitHub не попадают. Только сгенерированный HTML с агрегатами.
